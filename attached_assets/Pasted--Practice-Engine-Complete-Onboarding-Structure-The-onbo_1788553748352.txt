# Practice Engine — Complete Onboarding Structure

The onboarding should be **structured, fast, and purposeful**. Every screen should clearly tell the user whether they **select, type, choose from a dropdown, or complete an assessment**.

---

## STEP 1 — Welcome

### Purpose

Introduce what the Practice Engine does and establish the core promise.

### User action

**No typing. No form.**

### Screen content

**Build Your Coaching Practice**

Become a better coach. Improve your delivery. Build your methodology. Build your brand. Turn your experience into expertise, IP, courses, and products.

**Button:** `Get Started`

# STEP 5 — Coaching Skills Assessment

### Purpose

Establish the coach's starting skill level.

This should **not be a self-rating form alone**.

It should eventually become a combination of **questions + scenarios + AI evaluation**.

### Part A — Quick Self-Assessment

User selects a score from **1–5** for:

* Listening
* Questioning
* Reframing
* Challenging
* Accountability
* Session structure
* Handling resistance
* Intervention selection
* Coaching judgment

Example:

**How confident are you at handling a resistant client?**

`1  2  3  4  5`

---

### Part B — Mini Scenario

The system presents a coaching situation.

Example:

> **Client:**
> “I've already tried everything. Nothing is going to change.”

The user chooses from several possible responses.

**User action:** Select one answer.

The system evaluates the decision.

---

### Part C — Optional Practice

The user can enter a short live simulation.

**User action:** Type response or interact through the simulator.

This creates the first **Practice Performance Record**.

# Important Onboarding Rule

The onboarding should use **four interaction types only**:

| Interaction                | Used For                                                              |
| -------------------------- | --------------------------------------------------------------------- |
| **Select cards**           | Goals, coaching type, development preferences, IP ambitions           |
| **Dropdown**               | Experience level, years coaching, time commitment, structured choices |
| **Text input**             | Name, niche, audience, positioning                                    |
| **Text area**              | Experiences, reflections, methodology, lessons                        |
| **Interactive simulation** | Actual coaching skill assessment                                      |

The system should **avoid unnecessary typing**. The only places requiring substantial writing are where the coach's own experience, knowledge, methodology, or thinking is genuinely valuable.

Most importantly, onboarding isn't just **“tell us about yourself.”**

It should already perform the Practice Engine's core transformation:

**PROFILE → ASSESS → EXPERIENCE → REFLECT → PRACTICE → DISCOVER EXPERTISE → DEFINE DIRECTION → CREATE DEVELOPMENT PLAN → ENTER PRACTICE ENGINE**
