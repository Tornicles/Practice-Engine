# Connected OS

The seven dashboards now share one flywheel in `os/`.

- Practice, sessions, experiences, and published content write events.
- A won opportunity creates a client in status `new` (not active).
- Home overall state is the same condition set as the rest of the product.
- Messages cannot add a fourth Today job (WIP cap 3).
- `VITE_PRACTICE_LIVE=1` overlays `GET /api/home` when the API server is running.
