# Batch 8 — Investigation, Correction, and Reset

Status: design. Owner: Investigation & Correction (Engine 11). Push C.

```
Condition → Investigation → Evidence → Finding → Hypothesis → Root cause
  → Correction → Measurement → Effective | Failed → Prevent or Reopen
```

Insufficient Evidence never opens a case. Noise metrics cannot trigger content investigations.

A finding is not a root cause. Root cause cannot rest on assumption or ai_hypothesis alone.

Correction.effective requires a later measurement in the stated window. Checkbox done is verifying, never effective. Failed verify reopens the investigation.

Reset: work inventory, decay flags, fate keep | simplify | end. Apply uses the item's own cancel/retire transition. Evidence and events are not deleted.

AI may draft findings and hypotheses. It may not accept root cause, mark effective, or apply reset fate.

No Investigation dashboard. Home lists open cases.

Done when a declining skill opens a case, a correction cannot be called effective without a later statistic, and reset can end dead work without erasing proof.
