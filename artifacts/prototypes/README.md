# Forge prototypes

Clickable HTML prototypes of the Forge AI personal trainer app. Open directly in a browser (single files, zero dependencies).

- `forge-app.html` — full app prototype (onboarding, Train, Fuel with camera/voice grocery capture, Run, Progress, Coach, Profile).
- `forge-app-3d-standalone.html` — 3D-coach build: all 48 exercise demos are real videos of coaches Marcus (male) and Maya (female). ~7MB, everything inlined.

The React Native mobile app source lives in `../mobile/`.
